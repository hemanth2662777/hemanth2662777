# ♿ Accessibility

The animation system includes accessibility considerations.

### Reduced Motion

Users who enable reduced-motion preferences receive a simplified experience.

```css
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 1ms !important;
        transition-duration: 1ms !important;
    }
}
```

### Keyboard Accessibility

Interactive elements include visible keyboard focus states.

### Responsive Interaction

Animations are adjusted for:

* Desktop
* Tablet
* Mobile
* Touch devices

# ⚡ Performance Principles

The animation system prioritizes GPU-friendly properties such as:

```text
transform
opacity
filter
```

Instead of repeatedly animating expensive layout properties.

The system also uses:

* `will-change`
* `transform`
* `backface-visibility`
* hardware-friendly transitions
* reduced-motion support
* mobile motion tuning
